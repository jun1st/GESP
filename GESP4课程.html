第 1 课指针：存"地址"的变量▾
🎯 本节目标：1. 理解"地址"和"指针"；2. 会写 int *p = &x; 并用 *p 解引用。

📖 讲解

  • 变量住在内存里，每个变量都有自己的地址（就像房间号）。
  • 指针就是"存地址的变量"：int *p = &x; 让 p 记住 x 的房间号。
  • & 是取地址，*p 是解引用——"顺着地址找到那个变量"。
  • 改 *p 就等于改 x，因为指向的是同一个变量！
#include <iostream>
using namespace std;
int main() {
    int x = 10;
    int *p = &x;        // p 存 x 的地址
    cout << *p << endl; // 10：顺着地址取值
    *p = 20;            // 改 *p 就是改 x
    cout << x << endl;  // 20
    return 0;
}
📌 本节小结：& 取地址，* 解引用；指针存的是地址，*p 才是它"指向的变量"。

第 2 课二维及多维数组：表格▾
🎯 本节目标：1. 会定义二维数组；2. 会用双重循环遍历（外层行、内层列）。

📖 讲解

  • 二维数组像一张表格：a[i][j] 表示第 i 行第 j 列（下标还是从 0 开始）。
  • 遍历套路：外层循环管行，内层循环管列。
  • 二维数组可以做矩阵题、图形题（画 X、日字、N 字都是它的天下）。
#include <iostream>
using namespace std;
int a[105][105];
int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];
    for (int i = 0; i < n; i++) {   // 每行求和
        int s = 0;
        for (int j = 0; j < m; j++) s += a[i][j];
        cout << s << endl;
    }
    return 0;
}
📌 本节小结：a[行][列]；外层管行、内层管列；图形题先想清楚 i、j 的关系再打字符。

第 3 课结构体：把数据"打包"▾
🎯 本节目标：1. 会定义 struct；2. 会用点号 . 访问成员；3. 会用结构体数组存多个对象。

📖 讲解

  • struct 让我们自己造一种"新类型"，把相关数据打包：比如学生 = 名字 + 分数。
  • 访问成员用点号：s.name、s.score。
  • 结构体数组 Student a[100]; 可以存全班同学！
#include <iostream>
#include <string>
using namespace std;
struct Student {
    string name;
    int score;
};
int main() {
    Student s;
    s.name = "小明";
    s.score = 95;
    cout << s.name << " " << s.score << endl;
    return 0;
}
📌 本节小结：struct = 自定义打包类型；用 . 访问成员；还能做结构体数组、结构体指针。

第 4 课函数：定义、调用、形参实参、作用域▾
🎯 本节目标：1. 会写函数并调用；2. 分清形参和实参；3. 知道全局/局部变量的作用域。

📖 讲解

  • 函数 = 把一段代码"打包"起来，起个名字，随时调用（代码的积木）。
  • 形参：函数定义里的小括号占位；实参：调用时给的真实值。
  • 全局变量写在所有函数外面，谁都能用；局部变量写在 { } 里，出括号就"消失"。
  • 返回结果用 return 值;，没有结果就写 void。
#include <iostream>
using namespace std;
int add(int a, int b) {   // a、b 是形参
    return a + b;
}
int main() {
    cout << add(3, 5) << endl;  // 3、5 是实参，输出 8
    return 0;
}
📌 本节小结：形参是"占位"，实参是"真值"；函数外 = 全局，函数内 = 局部；void 表示没有返回值。

第 5 课参数传递：值、引用、指针▾
🎯 本节目标：1. 知道值传递改不动外面；2. 会用引用 & 和指针直接改外面。

📖 讲解

  • 值传递 f(int x)：把值复制一份进去，函数里怎么改都不影响外面。
  • 引用传递 f(int &x)：直接"贴上"外面的变量，改它外面就变。
  • 指针传递 f(int *x)：把地址传进去，用 *x 改外面的变量。
  • 想"换掉"外面的值（比如交换两个数），就用引用或指针。
#include <iostream>
using namespace std;
void f1(int x) { x = 100; }      // 值传递：外面不变
void f2(int &x) { x = 100; }     // 引用传递：外面变 100
void f3(int *x) { *x = 100; }    // 指针传递：外面也变
int main() {
    int a = 1, b = 1, c = 1;
    f1(a); f2(b); f3(&c);
    cout << a << " " << b << " " << c << endl; // 1 100 100
    return 0;
}
📌 本节小结：值传递复制一份（改不动外面）；引用 & 和指针 * 都能改外面；交换两个数用引用或指针。

第 6 课递推算法：一步一步往前推▾
🎯 本节目标：1. 会写递推关系式；2. 能用数组"从前往后"推（如斐波那契）。

📖 讲解

  • 递推：从已知的"开头几项"出发，用关系式一步步推出后面的项。
  • 经典例子：爬楼梯，第 i 阶只能从 i-1 或 i-2 阶上来，所以 f[i] = f[i-1] + f[i-2]。
  • 套路：先找初始值（f[1]、f[2]），再写关系式，最后 for 循环推到底。
#include <iostream>
using namespace std;
int f[50];
int main() {
    int n;
    cin >> n;
    f[1] = 1; f[2] = 1;              // 初始值
    for (int i = 3; i <= n; i++)
        f[i] = f[i - 1] + f[i - 2];  // 递推关系式
    cout << f[n] << endl;             // 第 n 项
    return 0;
}
📌 本节小结：递推 = 初始值 + 关系式 + 循环；斐波那契 f[i]=f[i-1]+f[i-2] 是最典型的例子。

第 7 课排序算法：冒泡、插入、选择▾
🎯 本节目标：1. 会写冒泡排序；2. 知道插入、选择的思想；3. 理解"稳定性"。

📖 讲解

  • 冒泡：相邻两个比较，大的往后"冒"，每趟把最大的送到最后。
  • 选择：每趟挑最小的放到最前面。
  • 插入：像抓扑克牌，把新牌插到已排好序列的合适位置。
  • 稳定性：相同元素排序后相对顺序不变，叫稳定（冒泡、插入稳定，选择不稳定）。
#include <iostream>
using namespace std;
int main() {
    int n, a[105];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n - 1; i++)            // 冒泡排序
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
    return 0;
}
📌 本节小结：冒泡每趟冒最大的、选择每趟挑最小的、插入像插扑克牌；稳定 = 相同元素顺序不变。

第 8 课文件读写与异常处理▾
🎯 本节目标：1. 会用 freopen 把输入输出重定向到文件；2. 了解 try-catch 异常处理。

📖 讲解

  • 考试看到"文件读写"提示，就在 main 开头加两行 freopen，之后 cin/cout 照常用。
  • freopen("in.txt", "r", stdin) 从 in.txt 读；freopen("out.txt", "w", stdout) 写到 out.txt。
  • 异常处理：把可能出错的代码放进 try，出错时 catch 接住，程序不会直接崩。
#include <iostream>
#include <cstdio>
using namespace std;
int main() {
    // freopen("in.txt", "r", stdin);   // 从文件读入
    // freopen("out.txt", "w", stdout); // 写到文件
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
📌 本节小结：freopen("文件名","r",stdin) 读、("w",stdout) 写；try 里放可能出错的代码，catch 接住异常。
