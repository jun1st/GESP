📌 三级学什么？

考纲知识内容：数据编码（原码/反码/补码）、进制转换（二/八/十/十六）、位运算（& | ~ ^ << >>）、算法概念与描述、C++ 一维数组、字符串及其函数、枚举法、模拟法。
🎯 知识目标：掌握数据编码、进制转换、位运算等知识，掌握一维数组、字符串及函数的使用，能够独立使用模拟法、枚举法解决对应的算法问题。题型：单选 15×2 + 判断 10×2 + 编程 2×25 ｜ 考试时间：120 分钟。
💡 学习建议：这一级开始"上难度"了！先打好位运算和进制的底子，再练数组和字符串，最后用枚举/模拟解决小问题。每课结尾有"考一考"，学完记得打勾打卡。

进度 0 / 6 课

第 1 课数据编码：原码、反码、补码▾
🎯 本节目标：1. 知道负数在电脑里是怎么存的；2. 会写 8 位原码、反码、补码。

📖 讲解

电脑里存数字也有"正负"。三个概念要分清：

  • 原码：最高位是符号位（0 正 1 负），其余位照抄数值。+5 = 0000 0101，-5 = 1000 0101。
  • 反码：正数不变；负数 = 符号位不变、其余位全部取反（0 变 1、1 变 0）。-5 的反码 = 1111 1010。
  • 补码：正数不变；负数 = 反码再 +1。-5 的补码 = 1111 1011。

为什么电脑用补码？因为 减法可以变成加法（A - B = A + B 的补码），电路只要会加法就行；而且 0 只有一种表示，不会出现"+0/-0"打架。

// 以 -5 为例（8 位）：
// 原码：1000 0101
// 反码：1111 1010   （符号位不变，其余取反）
// 补码：1111 1011   （反码 + 1）
// 电脑里存的都是补码！
📌 本节小结：原码 = 符号位 + 数值；反码 = 负数取反（符号位不动）；补码 = 反码 + 1。存负数用补码，减法变加法。

第 2 课进制转换：二、八、十、十六▾
🎯 本节目标：1. 会在二进制、八进制、十进制、十六进制之间转换；2. 记住十六进制用 A~F 表示 10~15。

📖 讲解

  • 十六进制有 16 个符号：0~9、A(10)、B(11)、C(12)、D(13)、E(14)、F(15)。
  • 4 位二进制 = 1 位十六进制，所以十六进制是二进制的"缩写"，超好用。
  • 二进制转十进制：把"1"所在的份量加起来（1、2、4、8、16……）。
  • 十进制转二进制：不断"除 2 取余"，余数倒着写。
#include <iostream>
using namespace std;
int main() {
    int x = 26;
    cout << dec << x << endl;  // 26（十进制）
    cout << hex << x << endl;  // 1a（十六进制）
    cout << oct << x << endl;  // 32（八进制）
    return 0;
}
📌 本节小结：十六进制 A~F 对应 10~15；4 位二进制 = 1 位十六进制；转十进制用"份量相加"，转二进制用"除 2 取余倒着写"。

第 3 课位运算：& | ~ ^ << >>▾
🎯 本节目标：1. 会用 6 种位运算；2. 记住"左移 = ×2ⁿ、右移 = ÷2ⁿ"；3. 会判断奇偶（x&1）。

📖 讲解

  • & 按位与：两位都是 1 结果才是 1。
  • | 按位或：有一个 1 就是 1。
  • ^ 按位异或：不同为 1，相同为 0。
  • ~ 按位取反：0 变 1，1 变 0。
  • << 左移 n 位 = 乘 2ⁿ；>> 右移 n 位 = 除 2ⁿ（向下取整）。
  • 妙用：判断奇数用 x & 1（奇数最后一位是 1）；取第 k 位用 (x >> k) & 1。
#include <iostream>
using namespace std;
int main() {
    int a = 5, b = 3;          // 0101 和 0011
    cout << (a & b) << endl;   // 1
    cout << (a | b) << endl;   // 7
    cout << (a ^ b) << endl;   // 6
    cout << (1 << 4) << endl;  // 16：1 左移 4 位 = ×16
    return 0;
}
📌 本节小结：位运算直接对二进制位操作；左移 = ×2ⁿ，右移 = ÷2ⁿ；x&1 判断奇偶，异或"相同为 0、不同为 1"。

第 4 课一维数组：一排有编号的格子▾
🎯 本节目标：1. 会定义数组并理解下标从 0 开始；2. 会用循环遍历数组（求和、找最大）。

📖 讲解

  • 数组 = 一排格子，每个格子有编号（下标从 0 开始）。
  • 定义：int a[105]; 表示最多放 105 个整数。用 a[0]、a[1]… 访问。
  • 遍历套路：for (int i = 0; i < n; i++) 把每个格子读一遍/算一遍。
  • 注意：下标越界（比如访问 a[n]）是未定义行为，千万别写！
#include <iostream>
using namespace std;
int main() {
    int n, a[105], mx = -1000000000;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++)
        if (a[i] > mx) mx = a[i];
    cout << mx << endl;   // 输出最大值
    return 0;
}
📌 本节小结：下标从 0 开始；循环 i 从 0 到 n-1 遍历；找最大就"比一比，留下大的"。

第 5 课字符串及其函数▾
🎯 本节目标：1. 会用 string 存文字；2. 会用 size/find/substr/toupper 等常用函数。

📖 讲解

  • string s = "Hello"; 字符串就像一个"字符数组"，但更好用。
  • s.size() 长度；s[i] 取第 i 个字符（还是从 0 开始）。
  • s.find("llo") 找子串位置（找不到返回很大的数）；s.substr(起点, 长度) 截取。
  • 大小写转换用 <cctype> 的 tolower/toupper。
#include <iostream>
#include <string>
#include <cctype>
using namespace std;
int main() {
    string s = "Hello";
    cout << s.size() << endl;          // 5
    cout << s[0] << endl;              // H
    cout << s.find("llo") << endl;     // 2
    cout << s.substr(1, 3) << endl;    // ell
    cout << (char)toupper('a') << endl; // A
    return 0;
}
📌 本节小结：string 常用四件套——size 长度、[] 取字符、find 找位置、substr 截取；大小写用 tolower/toupper。
← 上一课下一课：枚举与模拟 →
第 6 课枚举法与模拟法▾
🎯 本节目标：1. 会用枚举（穷举）解决小数据问题；2. 会"模拟"：照着规则一步步演。

📖 讲解

  • 枚举法：把所有可能的情况都试一遍，再用 if 筛选符合条件的。数据范围小的时候最管用。
  • 模拟法：题目说怎么做，程序就照着一步步做（比如模拟游戏回合、模拟时间流逝）。
  • 这两招是三级编程题的核心武器，一定要练熟！
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    for (int x = 1; x <= n; x++) {      // 枚举每一个数
        if (x % 3 == 0) cout << x << " ";  // 条件筛选
    }
    cout << endl;
    return 0;
}
📌 本节小结：枚举 = 全部试一遍 + if 筛选；模拟 = 照着规则一步步演。看到"数据不大 + 情况不多"就想到枚举！
