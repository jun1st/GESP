GESP C++ 八级课程

八级通关 = 组合数学 + 图论 + 算法优化，C++ 高手毕业！

📌 八级学什么？

考纲知识内容：计数原理（加法/乘法）、排列与组合、杨辉三角、倍增法、代数与平面几何（初中数学）、图论算法及综合应用（最小生成树、单源最短路径）、较复杂算法的空间和时间效率分析、算法优化。

💡 学习建议：八级 = 组合数学 + 图论 + 复杂度分析。把"为什么这个算法更快"想明白，比背代码更重要——这是从"会写"到"会选"的升级。

第 1 课计数原理：加法与乘法▾
🎯 本节目标：1. 分清"分类相加、分步相乘"；2. 会数方案总数。

📖 讲解

  • 加法原理：做一件事有 n 类办法（选一类就行），总数 = 每类数量相加。
  • 乘法原理：做一件事要分 n 个步骤（每步都要做），总数 = 每步数量相乘。
  • 记法：分类用加、分步用乘。
#include <iostream>
using namespace std;
int main() {
    // 例：3 件上衣 × 4 条裤子，搭配 = 12 种（乘法原理）
    int shirts = 3, pants = 4;
    cout << shirts * pants << endl;   // 12
    return 0;
}
📌 本节小结：分类 → 加法；分步 → 乘法。先想清楚是"选一类"还是"走完所有步骤"。

第 2 课排列与组合▾
🎯 本节目标：1. 分清排列（有序）和组合（无序）；2. 会写组合数 C(n,k)。

📖 讲解

  • 排列讲究顺序：第一名、第二名不一样，A(n,k) = n×(n-1)×…×(n-k+1)。
  • 组合不讲究顺序：选出哪几个人就行，C(n,k) = A(n,k) ÷ k!。
  • 计算组合数要小心溢出，用"边乘边除"。
#include <iostream>
using namespace std;
long long C(int n, int k) {
    if (k > n) return 0;
    long long res = 1;
    for (int i = 1; i <= k; i++)
        res = res * (n - i + 1) / i;   // 边乘边除，防溢出
    return res;
}
int main() {
    int n, k;
    cin >> n >> k;
    cout << C(n, k) << endl;           // C(n,k)
    return 0;
}
📌 本节小结：排列分顺序、组合不分；C(n,k) 边乘边除防溢出。

第 3 课杨辉三角▾
🎯 本节目标：1. 会按规则构造杨辉三角；2. 知道它藏着组合数。

📖 讲解

  • 杨辉三角：每行首尾是 1，中间每个数 = 上面两个数之和。
  • 妙用：第 n 行第 k 个数正好等于 C(n,k)（组合数）！
  • 和 (a+b)ⁿ 展开的系数一模一样（二项式定理）。
#include <iostream>
using namespace std;
int a[20][20];
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        a[i][0] = a[i][i] = 1;                    // 首尾是 1
        for (int j = 1; j < i; j++)
            a[i][j] = a[i-1][j-1] + a[i-1][j];    // 上面两个相加
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) cout << a[i][j] << " ";
        cout << endl;
    }
    return 0;
}
📌 本节小结：首尾 1、中间 = 上两个之和；第 n 行第 k 个就是 C(n,k)。

第 4 课倍增法：步子翻倍的智慧▾
🎯 本节目标：1. 知道倍增"每次翻倍"的思想；2. 会写快速幂（倍增的经典应用）。

📖 讲解

  • 倍增：步子按 1、2、4、8…翻倍，几步就能跳到很远（用在快速幂、跳表、LCA）。
  • 快速幂：求 aᵇ，把 b 看成二进制，底数不断平方，只用 O(log b) 次乘法。
  • 题目常要求"对 m 取模"，防止溢出。
#include <iostream>
using namespace std;
long long powmod(long long a, long long b, long long m) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % m;   // 这一位是 1 就乘上去
        a = a * a % m;                  // 底数平方（翻倍）
        b >>= 1;                        // 指数右移一位
    }
    return res;
}
int main() {
    long long a, b, m;
    cin >> a >> b >> m;
    cout << powmod(a, b, m) << endl;   // a^b mod m
    return 0;
}
📌 本节小结：倍增 = 每次翻倍跳；快速幂 O(log b) 求 aᵇ，记得取模防溢出。

第 5 课代数与平面几何（初中数学）▾
🎯 本节目标：1. 会解一元、二元一次方程；2. 会算常见图形面积。

📖 讲解

  • 一元一次：ax + b = 0 → x = -b/a。
  • 二元一次：两个未知数两个方程，用代入消元或加减消元。
  • 面积公式：长方形 长×宽；三角形 底×高÷2；圆 πr²。
  • 编程题里常常"解出公式再写代码"，比暴力循环快得多。
📌 本节小结：方程用消元解；面积公式要背熟；能用数学公式就不硬循环。

第 6 课图论算法及综合应用：MST 与最短路▾
🎯 本节目标：1. 知道最小生成树（Kruskal/Prim）；2. 知道最短路径（Dijkstra/Floyd）；3. 会选合适的算法。

📖 讲解

  • 最小生成树：用最少的边把所有点连通且不形成环。Kruskal 按边权从小到大加边，Prim 从一个点慢慢往外长。
  • 最短路径：Dijkstra 求单源（一个起点到所有点，边权非负）；Floyd 求多源（任意两点，三重循环，O(n³)）。
  • 会做选择题（概念 + 复杂度），模板代码能看懂、能改。
// Floyd：任意两点最短路径（三重循环）
// g[i][j] 先初始化为很大（INF），有边就填边权
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (g[i][k] + g[k][j] < g[i][j])
                g[i][j] = g[i][k] + g[k][j];
📌 本节小结：MST 用最少的边连通所有点；Dijkstra 单源、Floyd 多源；Kruskal 加最小边、Prim 往外长。

第 7 课算法的时间和空间效率分析▾
🎯 本节目标：1. 会估算常见复杂度；2. 会按数据范围选算法。

📖 讲解

  • 大 O 表示"数据变大时，运行时间怎么涨"。常见排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。
  • 数循环：一层循环 O(n)、两层嵌套 O(n²)、二分 O(log n)、归并排序 O(n log n)。
  • 空间复杂度同理：数组开多大就说多大。
📌 本节小结：数循环层数估时间；n 到 10⁵ 就别用 O(n²) 了，想想二分、前缀和、哈希。

第 8 课算法优化：用数学打败暴力▾
🎯 本节目标：1. 会用数学公式代替循环；2. 会用前缀和把区间和变成 O(1)。

📖 讲解

  • 等差数列求和：循环加要 O(n)，用公式 (首项+末项)×项数÷2 直接 O(1)。
  • 前缀和：预处理 s[i] = a₁+…+aᵢ，之后任意区间和 = s[r] - s[l-1]，O(1)。
  • 还有记忆化（算过的存起来）、剪枝（不可能的提前排除）等优化技巧。
#include <iostream>
using namespace std;
int a[100005], s[100005];
int main() {
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s[i] = s[i-1] + a[i];        // 前缀和
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l-1] << endl;  // 区间和 O(1)
    }
    return 0;
}
📌 本节小结：数学公式 > 硬循环；前缀和让区间和变 O(1)；记忆化和剪枝都是"少干活"。
