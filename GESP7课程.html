GESP C++ 七级课程

图论与动态规划——算法高手的必修课！

📌 七级学什么？

考纲知识内容：数学库常用函数（三角/对数/指数）、复杂动态规划（二维动态规划、区间 DP、LIS、LCS、滚动数组）、图的定义及遍历、图论算法（DFS/BFS/泛洪 flood fill）、哈希表。
🎯 知识目标：掌握图的定义与遍历相关算法，掌握图论基本概念及基础算法，能使用二维动态规划、动态规划最值优化的知识完成复杂的动态规划算法。题型：单选 15×2 + 判断 10×2 + 编程 2×25 ｜ 考试时间：180 分钟。
💡 学习建议：图 = "朋友圈"（人和人的关系）；DP = "记下小问题的答案"；哈希 = "直接按名字找抽屉"。先懂类比，再写代码。

第 1 课数学库函数：三角、对数、指数▾
🎯 本节目标：1. 会用 sin/cos、log10/log2、exp；2. 知道它们都在 <cmath> 里。

📖 讲解

  • 三角函数：sin(x)、cos(x)（注意：参数是弧度，不是角度）。
  • 对数函数：log10(x) = 以 10 为底，log2(x) = 以 2 为底。
  • 指数函数：exp(x) = e 的 x 次方（e ≈ 2.718）。
  • 考试常考"会读函数名、知道它算什么"，写代码前先想清楚定义域（log 里不能是负数或 0）。
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    cout << sin(0) << endl;        // 0
    cout << log10(1000) << endl;   // 3
    cout << log2(8) << endl;       // 3
    cout << exp(1) << endl;        // e ≈ 2.71828
    return 0;
}
📌 本节小结：sin/cos 管角度、log10/log2 管对数、exp 管 e 的次方；都来自 <cmath>。

第 2 课复杂动态规划：二维、区间、LIS、LCS▾
🎯 本节目标：1. 会用 dp[i][j] 二维表格；2. 认识 LIS、LCS；3. 知道滚动数组省空间。

📖 讲解

  • 二维 DP：用 dp[i][j] 这张"表格"记答案，比如区间 DP 记 dp[i][j] = 区间 i~j 的答案。
  • LIS：最长上升子序列——在序列里挑一个"越来越大的子序列"，越长越好。
  • LCS：最长公共子序列——两个字符串共同的最长"子序列"（可以跳着选，顺序不变）。
  • 滚动数组：很多 DP 只用到上一行，用两行数组"滚着用"，把空间从 O(n²) 省到 O(n)。
#include <iostream>
using namespace std;
int a[1005], dp[1005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int ans = 0;
    for (int i = 1; i <= n; i++) {        // LIS 最长上升子序列
        dp[i] = 1;
        for (int j = 1; j < i; j++)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    cout << ans << endl;
    return 0;
}
📌 本节小结：dp[i][j] 是二维表格；LIS 找最长上升子序列、LCS 找最长公共子序列；滚动数组省空间。

第 3 课图的定义与遍历▾
🎯 本节目标：1. 知道图 = 顶点 + 边；2. 会分有向/无向；3. 会用 DFS/BFS 遍历图。

📖 讲解

  • 图就像"朋友圈"：顶点是人，边是朋友关系。
  • 无向图：边没有方向（你认识我，我也认识你）；有向图：边有方向（我关注了你）。
  • 顶点的度 = 连着它的边数；有向图里分入度（指向它的）和出度（它指出的）。
  • 存图：邻接矩阵 g[u][v]（简单直观）或邻接表（省空间）。遍历用 DFS/BFS。
#include <iostream>
using namespace std;
int g[105][105], n, m;   // 邻接矩阵
bool vis[105];
void dfs(int u) {        // 深度优先遍历
    vis[u] = true;
    cout << u << " ";
    for (int v = 1; v <= n; v++)
        if (g[u][v] && !vis[v]) dfs(v);
}
📌 本节小结：图 = 顶点 + 边；无向图边没方向、有向图有方向；度 = 连着几条边；邻接矩阵/邻接表存图，DFS/BFS 遍历。

第 4 课图论算法：泛洪 flood fill▾
🎯 本节目标：1. 知道泛洪算法"从起点往四周蔓延"；2. 会用 DFS 数连通块。

📖 讲解

  • 泛洪算法（flood fill）：从起点开始，向上下左右"蔓延"，把连成一片的格子全部标记。
  • 典型应用：数岛屿（几块 # 连在一起算 1 个岛）、画图软件的"油漆桶填充"。
  • 四连通是上下左右 4 个方向；八连通再加 4 个斜角。
#include <iostream>
using namespace std;
int n, m;
char mp[105][105];
bool vis[105][105];
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
void flood(int x, int y) {
    vis[x][y] = true;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m
            && !vis[nx][ny] && mp[nx][ny] == '#')
            flood(nx, ny);   // 蔓延到下一格
    }
}
📌 本节小结：flood fill = 从起点四周蔓延，把连通块全部标记；数岛屿、油漆桶都是它。

第 5 课哈希表：直接按名字找抽屉▾
🎯 本节目标：1. 知道哈希 = "算出位置直接拿"；2. 了解冲突和解决方法；3. 会用"桶"统计出现次数。

📖 讲解

  • 哈希表：用哈希函数算出数据该放哪个"抽屉"，查找平均只要 O(1)，超快。
  • 冲突：两个不同的 key 算出同一个位置 → 用链地址法（一个位置挂一串）或开放寻址解决。
  • 简单应用：用数组当"桶"，统计每个字母/数字出现几次。
#include <iostream>
#include <string>
using namespace std;
int cnt[26];
int main() {
    string s;
    cin >> s;
    for (char c : s) cnt[c - 'a']++;   // 用"桶"计数
    for (int i = 0; i < 26; i++)
        if (cnt[i]) cout << char('a' + i) << ":" << cnt[i] << endl;
    return 0;
}
📌 本节小结：哈希 = 算位置直接取（平均 O(1)）；冲突用链地址/开放寻址解决；桶计数是最简单用法。
