第一部分：计算机基础知识（考客观题）

1. 计算机的存储

存储单位（必背）

  • 1 Byte（字节）= 8 bit（位）
  • 1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB，1 TB = 1024 GB
注意：换算率是 1024，不是 1000！

三类存储器的区别（二级重点）

名称全称特点断电后
RAM随机存取存储器可读可写，速度较快，内存（主存）数据丢失
ROM只读存储器只能读，一般不能写，存放启动程序（固件）数据保留
Cache高速缓冲存储器位于 CPU 和主存之间，速度最快、容量小、价格贵数据丢失

常见考点：

  • 断电后数据丢失的是 RAM（还有 Cache），不丢失的是 ROM 和硬盘（外存）。
  • 速度排序：Cache > RAM > 硬盘（外存）。
  • 计算机运行时，程序和正在处理的数据要放进 内存（RAM） 里。

2. 计算机网络

网络分类（按覆盖范围）

类型中文覆盖范围例子
LAN局域网一栋楼、一个学校家里 / 学校机房
MAN城域网一座城市城市主干网
WAN广域网全国、全球互联网

从小到大：LAN < MAN < WAN

网络分层模型

  • OSI 七层模型：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层（记忆口诀：物数网传会表应）
  • TCP/IP 四层模型：网络接口层 → 网际层 → 传输层 → 应用层

常见协议（必背）

协议作用默认端口
HTTP / HTTPS网页传输（HTTPS 是加密版）80 / 443
FTP文件传输21
DNS把域名翻译成 IP 地址53
SMTP / POP3发送 / 接收邮件25 / 110
TCP传输层，可靠、面向连接（慢而稳）—
UDP传输层，不可靠、无连接（快）—

IP 地址与子网

  • IPv4 地址是 4 段数字，每段 0~255，例如 192.168.1.1。
  • 私有地址（内网用，不上公网）：10.x.x.x、172.16~31.x.x、192.168.x.x。
  • 127.0.0.1 是回环地址（本机），也叫 localhost。
  • 子网掩码：如 255.255.255.0 表示前 24 位是网络号，后 8 位是主机号。
  • 子网划分：把一个大的网络"借"主机位，切成多个更小的网络。

3. 程序设计语言

三种语言（必背）

语言特点
机器语言由 0 和 1 组成，计算机直接执行，效率最高但人很难写
汇编语言用助记符（如 MOV、ADD），需要翻译成机器语言
高级语言接近人类语言（C++、Python、Java 等），可读性好、易移植

编译 vs 解释

  • 编译型：把整个程序一次性翻译成机器码再运行，如 C、C++。要经过"编译 → 链接 → 运行"。
  • 解释型：一边翻译一边执行，如 Python。
考点：C++ 是编译型的高级语言。

4. 流程图

基本符号（必背）

符号形状作用
起止框圆角矩形（椭圆）开始 / 结束
输入输出框平行四边形读入、输出数据
处理框矩形赋值、计算等操作
判断框菱形条件判断，有"是/否"两个出口
流程线带箭头线段表示执行方向

三种基本结构

  1. 顺序结构：从上到下依次执行。
  2. 分支（选择）结构：按条件走某一条路，用菱形判断框。
  3. 循环结构：满足条件时重复执行，注意循环要有"出口"（条件不满足时结束）。
做题技巧：看到菱形判断框 → 分支；看到箭头折回去 → 循环。

5. ASCII 编码

原理：计算机里只存 0 和 1，所以每个字符都对应一个数字编码，存字符就是存这个数字。

四个必背值

字符空格'0''A''a'
ASCII 码32486597

推出来的常用值

  • '0'~'9'：48~57，所以 '9' = 57
  • 'A'~'Z'：65~90，所以 'Z' = 90
  • 'a'~'z'：97~122，所以 'z' = 122
  • 大写和小写相差 32：'A' + 32 = 'a'，'a' - 32 = 'A'

C++ 中的字符与编码互转

char c = 'A';
cout << int(c) << endl;        // 输出 65（字符转编码）
cout << char(98) << endl;      // 输出 b（编码转字符）

cout << char('A' + 32) << endl; // 输出 a（大小写转换）
int x = '7' - '0';              // 字符数字转数值：7
cout << char('0' + 5) << endl;  // 数值转字符数字：5
考点：'B' - 'A' = 1；'0' + 3 = '3'（字符形式）。

6. 数据类型与类型转换

常用类型

类型大小范围（大约）
int4 字节-21 亿 ~ 21 亿
long long8 字节±9.2 × 10¹⁸
float4 字节约 7 位有效数字
double8 字节约 15 位有效数字
char1 字节存字符或 -128~127
bool1 字节true / false

隐式类型转换（自动发生）

规则：小的自动变成大的（低 → 高）：

bool / char → int → long long → float → double

double d = 3;      // int 3 自动转成 double 3.0
int x = true;      // bool true 转成 1
char c = 'A';
int y = c;         // 'A' 转成 65

最容易错的：整数除法

int a = 5, b = 2;
double c = a / b;         // 结果是 2.0！不是 2.5
                          // 因为 a/b 先做整数除法得 2，再转 double
double d = (double)a / b; // 2.5（先把 a 强转成 double）
double e = 1.0 * a / b;   // 2.5
记住口诀：两个整数相除，结果还是整数（向零截断）。想得到小数，除法前先把其中一个转成 double。

强制类型转换

int x = int(3.9);      // 3（直接砍掉小数部分）
int y = (int)3.9;      // 3（C 风格）
double z = (double)5 / 2;  // 2.5

两个易错坑

  • int 溢出：int x = 2000000000 + 2000000000; 会溢出出错。数据可能很大时，用 long long。
  • 浮点数不能直接比相等：if (a == b) 对 double 不可靠，要用 if (fabs(a - b) < 1e-9)。

7. 多层分支结构

基本写法

if (条件1) {
    // 条件1成立
} else if (条件2) {
    // 条件1不成立但条件2成立
} else {
    // 都不成立
}

条件里常用：关系运算符 < <= > >= == !=，逻辑运算符 && || !。在 C++ 里，非 0 即为真，0 为假。

switch 语句（二级必考）

switch (表达式) {
    case 常量1: 语句; break;
    case 常量2: 语句; break;
    default: 语句;
}

三个要点：

  1. case 后面必须是常量（整数或字符），不能是变量或范围。
  2. 没有 break 会"穿透"：匹配后一直往下执行到 break 才停。这是最容易出判断/选择题的点。
  3. default 在都不匹配时执行，可以放在任意位置。

例子（成绩等级）：

int score; cin >> score;
int level = score / 10;        // 90~99 → 9，100 → 10
switch (level) {
    case 10:
    case 9:  cout << "A"; break;   // 10 和 9 一起处理（穿透技巧）
    case 8:  cout << "B"; break;
    case 7:  cout << "C"; break;
    default: cout << "D";
}

多层分支常见错误

  • 把 == 写成 =（一个是判断相等，一个是赋值）。
  • 悬空 else：else 永远和"最近的、还没配对的 if"配对。拿不准就加大括号。
  • 判断顺序：先判特殊/窄的条件，再判一般条件。

8. 多层循环结构（编程题灵魂）

三种循环

// for：知道循环次数时用
for (int i = 1; i <= n; i++) { ... }

// while：先判断再执行
while (条件) { ... }

// do-while：至少执行一次
do { ... } while (条件);

break 和 continue

  • break：跳出本层循环。
  • continue：跳过本次循环的后面部分，进入下一次。

嵌套循环：外层管"行"，内层管"列"

打印直角三角形：

int n; cin >> n;
for (int i = 1; i <= n; i++) {        // 外层：n 行
    for (int j = 1; j <= i; j++) {    // 内层：第 i 行打 i 个 *
        cout << "*";
    }
    cout << endl;                     // 每行结束换行
}
画"日字矩阵""X 字矩阵""N 字矩阵"这类真题，方法都一样：先看行列关系（i 和 j 满足什么条件才打字符），用 if 判断 + 内层循环打印。

数位分解（真题高频）

int n; cin >> n;
int sum = 0;
while (n > 0) {
    sum += n % 10;   // 取个位
    n /= 10;         // 去掉个位
}
cout << sum << endl; // 输出各位数字之和

套路：n % 10 取末位，n / 10 去掉末位。循环到 n 变成 0。（注意：如果 n 本来可能是 0，上面循环一次都不执行，结果正好是 0，没毛病。）

枚举（穷举）——百鸡问题

100 元买 100 只鸡：公鸡 5 元/只，母鸡 3 元/只，小鸡 1 元/3 只。

for (int g = 0; g <= 20; g++)          // 公鸡最多 20 只
    for (int m = 0; m <= 33; m++) {    // 母鸡最多 33 只
        int x = 100 - g - m;           // 小鸡数量由总数决定
        if (x >= 0 && x % 3 == 0 &&
            g * 5 + m * 3 + x / 3 == 100)
            cout << g << " " << m << " " << x << endl;
    }

枚举套路：把所有可能的情况都试一遍，用 if 筛选符合条件的。

判断素数（真题高频）

bool isPrime = true;
if (n < 2) isPrime = false;
for (int i = 2; i * i <= n; i++) {   // 只需试到 sqrt(n)
    if (n % i == 0) { isPrime = false; break; }
}

9. 常用数学函数

需要 #include <cmath>：

函数作用例子
abs(x)整数绝对值abs(-5) = 5
fabs(x)浮点绝对值fabs(-3.5) = 3.5
sqrt(x)平方根sqrt(16) = 4
max(a,b) / min(a,b)较大值 / 较小值max(3,7) = 7
pow(a,b)a 的 b 次方（返回 double）pow(2,10) = 1024
round(x)四舍五入round(3.5) = 4

随机数（大纲明确要求）

#include <cstdlib>
#include <ctime>

srand(time(0));        // 播种子（每次运行结果不同）
int x = rand() % 100;  // 生成 0~99 的随机数
注意：不播种子的话，每次运行 rand() 的结果都一样。

数学函数易错点

  • sqrt 里不能是负数。
  • pow 返回的是 double，比较结果要注意类型。
  • 浮点数比较用 fabs(a - b) < 1e-9，不要直接用 ==。

第四部分：历年真题（2023.3 ~ 2025.12 二级）

客观题之外，编程题真题主要有这些类型：

  • 图形输出：画三角形、X 字矩阵、日字矩阵、N 字矩阵、菱形、黄金格
  • 数位处理：数位之和、数字黑洞、自幂数、幂和数、优美的数字
