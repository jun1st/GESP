进度 0 / 8 课

第 1 课初等数论：数字世界的"基本零件"▾
🎯 本节目标：1. 分清素数/合数；2. 会求最大公约数 gcd、最小公倍数 lcm；3. 知道同余和质因数分解。

📖 讲解

  • 素数：只有 1 和它本身两个约数（2、3、5、7…）；合数：还有别的约数（4、6、8…）。1 既不是素数也不是合数。
  • gcd 最大公约数、lcm 最小公倍数，记住公式：lcm(a,b) = a × b ÷ gcd(a,b)。
  • 同余：a、b 除以 m 余数一样，就说 a ≡ b (mod m)。
  • 质因数分解：把数拆成质数相乘，如 12 = 2×2×3。
#include <iostream>
using namespace std;
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)   // 试到 sqrt(n) 就够了
        if (n % i == 0) return false;
    return true;
}
int main() {
    int n;
    cin >> n;
    cout << (isPrime(n) ? "是素数" : "不是素数") << endl;
    return 0;
}
📌 本节小结：素数=只有 1 和本身；gcd/lcm 是数论好搭档；判断素数试除到 sqrt(n) 就够。

第 2 课高精度运算：装不下的超级大数▾
🎯 本节目标：1. 知道 int/long long 装不下的大数要用数组存；2. 会写高精度加法。

📖 讲解

  • 100 位的大数 int 和 long long 都装不下，怎么办？一位一位存进数组，像列竖式一样算。
  • 套路：字符串读入 → 倒着存（个位存下标 0，方便进位）→ 逐位相加 → 处理进位 → 倒着输出。
  • 乘法、减法、除法思路一样：模拟手算竖式。
#include <iostream>
#include <string>
using namespace std;
int a[105], b[105], c[105];
int main() {
    string s1, s2;
    cin >> s1 >> s2;
    for (int i = 0; i < s1.size(); i++) a[s1.size()-1-i] = s1[i]-'0';
    for (int i = 0; i < s2.size(); i++) b[s2.size()-1-i] = s2[i]-'0';
    int len = max(s1.size(), s2.size());
    for (int i = 0; i < len; i++) {
        c[i] += a[i] + b[i];
        if (c[i] >= 10) { c[i+1]++; c[i] -= 10; }  // 进位
    }
    if (c[len]) len++;
    for (int i = len-1; i >= 0; i--) cout << c[i];
    cout << endl;
    return 0;
}
📌 本节小结：大数逐位存数组；倒着存、逐位算、处理进位、倒着输出——"竖式搬家"。

第 3 课链表：手拉手的节点们▾
🎯 本节目标：1. 知道链表由"节点 + 指针"组成；2. 区分单链表、双链表、循环链表。

📖 讲解

  • 链表像小朋友手拉手：每个节点存自己的数据，还握着一个指向下一个的"指针"。
  • 单链表：只能从前往后走（next）。
  • 双链表：有 next 还有 prev，前后都能走。
  • 循环链表：最后一个又指回第一个，首尾相连。
  • 链表插入/删除快，但"按下标访问"慢——和数组正好互补。
#include <iostream>
using namespace std;
struct Node {
    int val;
    Node* next;
};
int main() {
    Node a, b, c;
    a.val = 1; b.val = 2; c.val = 3;
    a.next = &b; b.next = &c; c.next = nullptr;
    for (Node* p = &a; p != nullptr; p = p->next)
        cout << p->val << " ";   // 1 2 3
    cout << endl;
    return 0;
}
📌 本节小结：节点 = 数据 + 指针；单链表往后走、双链表前后走、循环链表首尾相连。

第 4 课辗转相除法与素数筛法▾
🎯 本节目标：1. 会用辗转相除法求 gcd；2. 知道埃氏筛"划掉倍数"的思路。

📖 讲解

  • 辗转相除法（欧几里得算法）：gcd(a,b) = gcd(b, a%b)，一直除到余 0，最后的除数就是答案。
  • 埃氏筛：先假设全是素数，然后从 2 开始，把每个素数的倍数全部"划掉"，剩下的就是素数表。
  • 唯一分解定理：每个大于 1 的整数都能唯一写成质数相乘。
#include <iostream>
using namespace std;
int gcd(int a, int b) {           // 辗转相除法
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
int main() {
    int a, b;
    cin >> a >> b;
    cout << gcd(a, b) << endl;
    return 0;
}
📌 本节小结：gcd 用辗转相除"余数接力"；埃氏筛划掉倍数求素数表；质因数分解唯一。

第 5 课二分查找与二分答案▾
🎯 本节目标：1. 会写有序数组的二分查找；2. 知道二分答案"判断后砍一半"的套路。

📖 讲解

  • 二分查找：猜中间的数，大了往左、小了往右，每次砍掉一半，O(log n) 飞快。
  • 前提：数组必须有序！
  • 二分答案：当"答案在一个范围内、能判断行不行"时，对答案二分：行就往一边走，不行就往另一边。
#include <iostream>
using namespace std;
int a[100005];
int main() {
    int n, x;
    cin >> n >> x;
    for (int i = 0; i < n; i++) cin >> a[i];
    int l = 0, r = n - 1, ans = -1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (a[mid] >= x) { ans = mid; r = mid - 1; }  // 第一个 >= x 的位置
        else l = mid + 1;
    }
    cout << ans << endl;
    return 0;
}
📌 本节小结：二分 = 每次砍一半；查找要数组有序；答案也能"二分"：判断行不行再缩范围。

第 6 课递归：函数调用自己▾
🎯 本节目标：1. 会写递归函数；2. 知道递归必须有"出口"；3. 能分析简单递归的复杂度。

📖 讲解

  • 递归 = 函数自己调用自己，把大问题拆成"小一号的自己"。
  • 两个必备零件：出口（最小的情况直接返回）+ 递推调用（变小再调用）。
  • 没有出口会无限调用，直到栈溢出崩溃。
  • 例子：n! = n × (n-1)!，出口是 0! = 1。
#include <iostream>
using namespace std;
int fact(int n) {
    if (n <= 1) return 1;       // 出口
    return n * fact(n - 1);     // 自己调用自己
}
int main() {
    int n;
    cin >> n;
    cout << fact(n) << endl;
    return 0;
}
📌 本节小结：递归 = 出口 + 自己调用自己；每次调用都把问题变小；没有出口会栈溢出。

第 7 课贪心算法：每次都选最好的▾
🎯 本节目标：1. 理解贪心"每步选当前最优"；2. 知道贪心不一定对，要验证。

📖 讲解

  • 贪心：每一步都选"眼前看起来最好"的，希望最后整体也最好。
  • 经典例子：找零钱用最少硬币——先拿大面额（10 元 → 5 元 → 1 元）。
  • 注意：贪心不是一定对！只有"局部最优能推出全局最优"时才能用，要会证明或验证。
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;                  // 需要找的钱
    int cnt = 0;
    cnt += n / 10;  n %= 10;   // 先拿 10 元
    cnt += n / 5;   n %= 5;    // 再拿 5 元
    cnt += n;                  // 剩下 1 元
    cout << cnt << endl;       // 最少硬币数
    return 0;
}
📌 本节小结：贪心每步选当前最优；用之前要想清楚"局部最优 = 整体最优"是否成立。

第 8 课分治算法：归并排序与快速排序▾
🎯 本节目标：1. 记住分治三步：分解 → 解决 → 合并；2. 知道归并、快排的思路。

📖 讲解

  • 分治 = 分而治之：把大问题拆成小问题，分别解决，再合并结果。
  • 归并排序：把数组分成两半，各自排好，再"合并"成有序的（合并两个有序序列很快）。
  • 快速排序：选一个"基准数"，比它小的放左边、大的放右边，再对两边递归。
#include <iostream>
using namespace std;
int a[100005], tmp[100005];
void mergeSort(int l, int r) {
    if (l >= r) return;                 // 出口
    int mid = (l + r) / 2;
    mergeSort(l, mid);                  // 分：左半
    mergeSort(mid + 1, r);              // 分：右半
    int i = l, j = mid + 1, k = l;      // 合并两个有序部分
    while (i <= mid && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    mergeSort(0, n - 1);
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    return 0;
}
📌 本节小结：分治三步 = 分解、解决、合并；归并先排两半再合并，快排选基准数分两边。
