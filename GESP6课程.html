GESP C++ 六级课程

树、搜索、动态规划——数据结构的大门打开啦！

📌 六级学什么？

考纲知识内容：树的定义构造与遍历、哈夫曼树、完全二叉树、二叉排序树、哈夫曼编码、格雷编码、深度优先搜索（DFS）、宽度优先搜索（BFS）、二叉树的搜索算法、简单动态规划（一维动态规划、简单背包）、面向对象思想与类的创建、栈/队列/循环队列。
🎯 知识目标：掌握树的基础知识，能分辨不同的树，根据不同的搜索算法遍历；掌握简单线性动态规划和简单背包问题。题型：单选 15×2 + 判断 10×2 + 编程 2×25 ｜ 考试时间：180 分钟。
💡 学习建议：树 = "家谱"、栈 = "叠盘子"、队列 = "排队"，先用生活类比建立直觉，再写代码。

第 1 课树的基本概念与遍历▾
🎯 本节目标：1. 知道树的根、父、子、叶子；2. 会先序/中序/后序三种遍历。

📖 讲解

  • 树就像家谱：最上面一个"根"，每个节点有父节点和若干子节点，没有子节点的叫叶子。
  • 三种遍历（记住"根"的位置）：先序根左右、中序左根右、后序左右根。
  • 考试常问：给你一棵树，写出某种遍历的顺序。
#include <iostream>
using namespace std;
struct Node { int v; Node *l, *r; };
void pre(Node* p) {          // 先序遍历：根 左 右
    if (!p) return;
    cout << p->v << " ";
    pre(p->l);
    pre(p->r);
}
// 中序：左 根 右；后序：左 右 根，把顺序换一下就行
📌 本节小结：树=家谱（根/父/子/叶）；先序根左右、中序左根右、后序左右根。

第 2 课哈夫曼树、完全二叉树、二叉排序树▾
🎯 本节目标：1. 认识三种特殊二叉树；2. 会判断是不是完全二叉树、二叉排序树。

📖 讲解

  • 完全二叉树：从上到下、从左到右一层层排，中间不能有空档。
  • 二叉排序树：左边都比根小、右边都比根大（中序遍历正好是排好序的）。
  • 哈夫曼树：带权路径最短的树，是压缩的基础（后面一课讲编码）。
📌 本节小结：完全二叉树没有空档；二叉排序树左小右大；哈夫曼树路径最短。

第 3 课哈夫曼编码与格雷编码▾
🎯 本节目标：1. 知道哈夫曼编码让"高频字符码更短"；2. 知道格雷编码相邻只有一位不同。

📖 讲解

  • 哈夫曼编码：出现次数多的字符用短码、少的用长码，整个文件就变小了（比如 ZIP 压缩）。
  • 格雷编码：相邻两个数字的二进制表示只有一位不同，用于传感器、电路，减少出错。
  • 这两个都是"编码"知识，选择题常考概念。
📌 本节小结：哈夫曼=高频短码（压缩）；格雷=相邻只变一位（防错）。

第 4 课深度优先搜索（DFS）与宽度优先搜索（BFS）▾
🎯 本节目标：1. 知道 DFS"一条路走到黑"；2. 知道 BFS"一层层扩散"（用队列）；3. 会判断该用哪个。

📖 讲解

  • DFS：像走迷宫"一条路走到黑，走不通就回头"，适合搜索所有方案（枚举路径、全排列）。
  • BFS：像"水波一圈圈扩散"，一层层往外走，第一次找到的就是最短路径。
  • 实现：DFS 常用递归；BFS 用队列。
#include <iostream>
#include <queue>
using namespace std;
struct Node { int v; Node *l, *r; };
void bfs(Node* root) {            // 层序遍历 = BFS
    queue<Node*> q;
    q.push(root);
    while (!q.empty()) {
        Node* p = q.front(); q.pop();
        cout << p->v << " ";
        if (p->l) q.push(p->l);
        if (p->r) q.push(p->r);
    }
}
📌 本节小结：DFS 走到黑再回头（递归），BFS 一层层扩散（队列、最短路径）。

第 5 课简单动态规划：爬楼梯与背包▾
🎯 本节目标：1. 知道 DP 是"记下子问题答案"；2. 会做爬楼梯；3. 知道 0/1 背包"装或不装"。

📖 讲解

  • 动态规划（DP）：把大问题拆成小问题，把小问题的答案记下来，避免重复计算。
  • 爬楼梯：到第 i 阶只能从 i-1 或 i-2 阶上来 → f[i] = f[i-1] + f[i-2]。
  • 0/1 背包：每个物品只有装或不装两种选择，用 dp[j] 记录容量 j 能装的最大价值。
#include <iostream>
using namespace std;
int f[100005];
int main() {
    int n;
    cin >> n;
    f[0] = 1; f[1] = 1;             // 初始值
    for (int i = 2; i <= n; i++)
        f[i] = f[i - 1] + f[i - 2]; // 从 i-1 或 i-2 跳上来
    cout << f[n] << endl;
    return 0;
}
📌 本节小结：DP = 子问题答案存起来复用；爬楼梯 f[i]=f[i-1]+f[i-2]；背包每件物品"装或不装"。

第 6 课面向对象 + 栈、队列、循环队列▾
🎯 本节目标：1. 知道"类=图纸、对象=成品"；2. 会用栈（后进先出）和队列（先进先出）。

📖 讲解

  • 面向对象：类（class）像"图纸"，对象是按图纸造出来的"成品"；三大特性：封装、继承、多态。
  • 栈：像叠盘子，后放上去的先拿走 —— 后进先出（LIFO）。
  • 队列：像排队，先来的先办事 —— 先进先出（FIFO）。
  • 循环队列：队尾满了就绕回头，省空间。
#include <iostream>
#include <stack>
#include <queue>
using namespace std;
int main() {
    stack<int> st;            // 栈：后进先出
    st.push(1); st.push(2);
    cout << st.top() << endl; // 2
    st.pop();
    queue<int> q;             // 队列：先进先出
    q.push(1); q.push(2);
    cout << q.front() << endl; // 1
    return 0;
}
📌 本节小结：类=图纸、对象=成品；栈后进先出（叠盘子）、队列先进先出（排队）。
