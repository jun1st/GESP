3. 给电脑说"人话"：程序语言

🤖 机器语言

10110000 00000101

6. 类型转换：整数和小数的"变身"

最著名的陷阱：5 ÷ 2 到底等于几？试试看！

✂️ 整数除法 int a/b
🍰 小数除法 (double)a/b
想得到小数，必须先变身成 double！
int a = 5, b = 2; double x = a / b; // 2.0，不是 2.5！先整数除法 double y = (double)a / b; // 2.5 ✅
⚠️ 两个坑：① int 太小会溢出，数大用 long long；② 浮点数比较用 fabs(a-b) < 0.000001，别用 ==。
🌿

🎮 switch 大冒险：忘写 break 会怎样？

x = 8，只匹配 case 8。勾上"去掉所有 break"，看输出怎么"穿"下去！

switch (x) { case 9: cout << "A"; break; case 8: cout << "B"; break; case 7: cout << "C"; break; default: cout << "D"; }
输出：B
🧠 没有 break，程序会"掉下去"继续执行，这就是穿透——选择题最爱考！
