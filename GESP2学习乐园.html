🧅 网络"分层"：快递是怎么一步步送到的？

数据出门就像寄快递，要一层层"打包"，收到再一层层"拆包"。OSI 有 7 层，TCP/IP 简化成 4 层。

🌐 OSI 七层（从上到下）
应用层 → 表示层 → 会话层 → 传输层 → 网络层 → 数据链路层 → 物理层。
口诀：应表会传网链物（倒着背：物数网传会表应）。
📦 TCP/IP 四层
应用层 → 传输层 → 网际层 → 网络接口层。
我们常说的 TCP（可靠）和 UDP（快速）就住在"传输层"。

🏷️ IP 地址与子网

IP 地址就像门牌号；子网掩码负责告诉你"哪些是邻居（同一网段）"。

📍 IPv4 地址
4 段数字，每段 0~255，比如 192.168.1.1。127.0.0.1 是"自己"（localhost）。
🏠 私有地址
家里/公司内网用的：10.x.x.x、172.16~31.x.x、192.168.x.x，不上公网。
🔀 子网掩码
255.255.255.0 表示前 24 位是网络号，后 8 位是主机号 → 一个网里最多 254 台设备。子网划分就是"借主机位"切出更小的网。
🏷️ IP 地址就像门牌号：192.168.1.1 是家里的"私有地址"，127.0.0.1 是"我自己的地址"。
📌 本节小结：LAN<MAN<WAN；分层像寄快递（OSI 口诀"应表会传网链物"）；HTTP 80、HTTPS 443、DNS 53；子网掩码 255.255.255.0 前 24 位是网络号。

第 3 课：程序设计语言

同样说"让 a 等于 5"，三种语言说法不一样。点一点，听听它们怎么自我介绍！

🎯 本节目标：1. 分清机器语言、汇编语言、高级语言；2. 知道编译型和解释型的区别；3. 记住 C++ 是编译型高级语言。
🤖 机器语言
01100101
10110000 00000101
我是 0 和 1！电脑直接听懂我，但我太难读了……
🔧 汇编语言
MOV AL, 5
我用英文缩写说话，比 0 和 1 好读一点，但还是要翻译。
✏️ C++（高级语言）
int a = 5;
我像英语一样好懂！C++ 会先"编译"成机器语言再运行。
🧠 记住：C++ 是编译型的高级语言；Python 是解释型（边翻译边运行）。
📌 本节小结：机器语言=0/1 直接执行；汇编=助记符要翻译；高级语言最好懂。C++ 先整体编译再运行。

第 6 课：数据类型转换

最著名的陷阱：5 ÷ 2 到底等于几？试试看！

🎯 本节目标：1. 知道隐式转换"小的自动变大的"；2. 会写强制转换 (double)a；3. 躲开整数除法和 int 溢出两个坑。
✂️ 整数除法 int a/b
🍰 小数除法 (double)a/b
想得到小数，必须先变身成 double！
int a = 5, b = 2; double x = a / b; // 2.0，不是 2.5！先整数除法 double y = (double)a / b; // 2.5 ✅
⚠️ 两个坑：① int 太小会溢出，数大用 long long；② 浮点数比较用 fabs(a-b) < 0.000001，别用 ==。
📌 本节小结：两个整数相除结果还是整数；想得小数先转 double；int 会溢出、double 不能直接比相等。

第 7 课：多层分支与 switch

🎯 本节目标：1. 会写 if-else if-else 多级判断；2. 知道 switch 的 case 必须是常量；3. 明白 break"穿透"和悬空 else。

  • else if (score >= 70) 等级 = C;
  • else if (score >= 60) 等级 = D;

🎮 switch 大冒险：忘写 break 会怎样？

x = 8，只匹配 case 8。勾上"去掉所有 break"，看输出怎么"穿"下去！

switch (x) { case 9: cout << "A"; break; case 8: cout << "B"; break; case 7: cout << "C"; break; default: cout << "D"; }
输出：B
🧠 没有 break，程序会"掉下去"继续执行，这就是穿透——选择题最爱考！
📌 本节小结：多层分支从上往下试；switch 漏 break 会穿透；else 跟最近的未配对 if；先判特殊情况再判一般情况。

第 8 课：多层循环与数位套路

选一个图形，按"一步"慢慢看电脑怎么用两层循环把它打出来！

🎯 本节目标：1. 会用嵌套循环打印图形（外层管行、内层管列）；2. 掌握"剥洋葱"数位分解套路（n%10、n/10）；3. 会用枚举穷举。
for (int i = 1; i <= n; i++) { // 外层：第 i 行 for (int j = 1; j <= n; j++) { // 内层：第 j 列 if (满足条件) cout << "*"; else cout << " "; } cout << endl; // 一行打完，换行 }
按"一步"开始吧！

🧅 数字剥洋葱：拆出每一位

输入一个数，看它怎么一位一位被"剥"出来（n%10 取个位，n/10 去掉个位）。

🧠 真题套路：数位之和、数字黑洞、自幂数……全靠"剥洋葱"！
📌 本节小结：外层管行、内层管列；n%10 取个位、n/10 去掉个位；枚举=把所有可能试一遍再用 if 筛选。

第 9 课：数学函数与随机数

输入两个数，点按钮调用 C++ 的数学函数！

🎯 本节目标：1. 会背 abs/fabs/sqrt/max/min/pow/round；2. 会用 rand() 和 srand(time(0))；3. 知道浮点数不能直接比相等。
点一个按钮试试～

🎲 掷骰子 = rand()

rand()%6+1 就能得到 1~6
🎲
#include <cstdlib> // rand、srand #include <ctime> // time srand(time(0)); // 播种，让每次都不一样 int x = rand() % 100; // 0~99 的随机数
🧠 小提醒：sqrt 里不能是负数；pow 返回的是 double；浮点数比较别用 ==，要用 fabs(a - b) < 1e-9。
📌 本节小结：数学函数都在 <cmath>；rand()%n 得 0~n-1，想 1~6 写 rand()%6+1；记得 srand(time(0)) 播种。
